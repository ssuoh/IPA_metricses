使い方

上のタブで5つの画面を切り替えます。次の順に見ると、自分の案件に使える基準値まで迷わずたどり着けます。

  1. 全体像で前提をつかむこの画面です。IPAの値がどんな開発の実績なのかを確認します。
  2. チェックで案件を判定する開発種別や言語など8項目を選ぶと、IPAの値を基準に使えるか、どの区分を参照すればよいかが出ます。結果はコピーして報告書に貼れます。チェックを開く →
  3. 基準値で実際の値を見る規模の尺度と開発種別を選ぶと、結合テストのテストケース密度や検出バグ密度が表示されます。開発規模と件数を入れると、自分の値がどの位置にあるかが分かります。基準値を開く →
  4. 分類軸で定義を確かめる区分の定義と、母集団に占める割合を調べます。用語で絞り込めます。行を押すと定義と件数が開きます。分類軸を開く →
  5. 注意で使う前の確認をする当てはめるときの注意点と、原典へのリンクがあります。正式な基準にする前に、原典の表で値を確認してください。注意を開く →
用語
P25、中央値、P75
値を小さい順に並べたとき、下から25%、50%、75%の位置にある値です。P25〜P75の範囲に全体の半分のプロジェクトが入ります。
KSLOC
ソースコード1,000行のことです。コメント行と空行は数えません。
FP、KFP
FPは機能の量で測るファンクションポイントです。KFPは1,000FPです。
現象数、原因数
現象数は、テストで見つかった不具合の事象の数です。原因数は、それを根本原因ごとにまとめて数えた数です。
改良開発
改修・保守と拡張をまとめた区分です。規模は追加、変更、削除した行の合計で、もとのシステムの規模は含みません。
知っておくと便利なこと
  • チェックで選んだ内容と、基準値に入れた数値は、この端末のブラウザに残ります。ほかの人には見えません。
  • チェックの結果にある「この区分の結合テスト基準値を見る」を押すと、該当する開発種別の基準値に移動します。
  • 分類軸の棒は、すべて0〜100%の同じ目盛りです。軸どうしで長さを比べられます。

    読むときの注意
    平均値は極端に大きい値に引っ張られています(例:SLOC規模、全開発種別のテストケース密度は中央値51.7に対して平均484.9)。基準には中央値とP25〜P75の範囲を使ってください。テストケースの数え方は各社で異なります。現象数と原因数は、提出しているプロジェクトの重なりが少ないため、両者の値をそのまま比べることはできません。改良開発の規模は追加、変更、削除の合計で、母体を含みません。

    案件チェック

    案件の属性を選ぶと、その場で判定が変わります。初期表示は入力例です。選んだ内容はこの端末に残ります。

    判定は、各区分が母集団に占める割合と、資料に書かれた分析対象の条件をもとにした目安です。割合が小さい区分は、値はあっても件数が少なく、ばらつきが大きくなります。

    当てはめるときの注意

    1. アジャイル、反復型には使えない反復型は直近6年で29件(2.1%)だけです。アジャイルという区分は選択肢にありません。
    2. ソースを変更するカスタマイズは「改良開発」で読む「パッケージ利用開発」はソースを変更しない開発を指します。ソースに手を入れる場合は、新規部分の比率で改修・保守(約10%未満)か拡張(約10〜90%)に当たります。資料の定義からの解釈です。
    3. テストケース密度は絶対値で比べないテストケースの数え方は各社の判断に任されています。自社の過去実績と並べて使うのが安全です。
    4. 改良開発の規模に母体を含めない改良開発のSLOCは追加、変更、削除の合計です。母体を含めた規模で密度を計算すると、IPAの値より低く出ます。
    5. データは2021年度まで事業終了により続刊の予定はありません。生成AIの利用など、それ以降の開発環境の変化は反映されていません。
    6. 業種別の値があるのは3業種だけ金融・保険業、情報通信業、製造業には別冊があります。ほかの業種は全業種の値を使うことになり、件数の多い業種の影響を受けます。

    このページの数値について
    割合と件数は、上記の資料から2026年11月に抜き出して整理したものです。「2022」の表示がある軸は分析データ集2022(直近6年、2016〜2021年度)、「白書2018-19」の表示がある軸はデータ白書2018-2019(近年6年間)の値です。版が違う軸どうしは母集団が異なります。

    結合テストの基準値は、分析データ集2022の表5-1-1〜5-1-4、表5-2-1〜5-2-4、表A3-3-5〜A3-3-10から転記しました。結合テストの行のN、P25、中央値、P75は、2回の読み取りで一致を確認しています。最小、最大、平均、標準偏差、総合テストの行、工程別の比率は1回の読み取りです。正式な基準として使う前に、必ず原典の表で確認してください。
